# Generated fixture provenance

All shipped test footage is generated by this repository; no user recordings,
external sky footage, identifiable people, location coordinates or camera secrets
are included. Generated fixtures and their generators follow the repository's
existing Apache-2.0 license. They are synthetic software tests, not observations.

`make fixtures` generates a six-second lossless FFV1 Matroska scene with two
scripted targets, blinking, stars, seeded noise, a global one-pixel shift and an
exposure step. JSON records exact centers, visibility, frame indices and media
time; its video SHA256 identifies the encoded bytes tested. Files are deliberately
ignored by git and regenerated locally; portable milestone ZIPs include this
explicitly public fixture only.

`uv run --project backend python scripts/benchmark_detection.py` generates H264
scenes at native 1280×720/20fps, CRF18 and CRF32, containing 18 separate combinations
of 1/3/5-pixel diameter, 12/64-gray-level contrast and .05/.2/1-second duration.
Each case lasts 48 frames, with the target starting at local frame20 and moving
8 native pixels per frame from (200,350). The detector sees decoded encoded video,
never the labels. Results retain every below-threshold case, misses, sampling
phase, false-candidate count, parameter hash and measured process time.

Further unit/integration fixtures include generated VFR/B-frame H264, a 120-second
FFV1 test pattern for pre/post context, local RTSP packetization, deliberate
corruption and interrupted capture. These validate behavior and failure states;
they do not establish real-world target identification or hardware reliability.
